# Product Image List

Use this file as a shopping-image checklist for the app.

Preferred image style:
- clean product photo
- square or near-square crop
- isolated object on light or transparent background
- no watermark
- front or 3/4 angle view

Suggested naming pattern:
- `category-product-name.webp`
